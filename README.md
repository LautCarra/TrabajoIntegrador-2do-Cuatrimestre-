 5.º 2.ª

 💻 Proyecto de Base de Datos

El objetivo de este trabajo es aplicar los conocimientos adquiridos durante el año mediante el diseño, desarrollo y documentación de una base de datos, utilizando distintas herramientas informáticas.

 🛠️ Herramientas y actividades

- 🗂️ Diagrama Entidad-Relación (Draw.io): representación gráfica de las entidades, sus atributos y las relaciones entre ellas.
- 🔗 Modelo Relacional (MySQL): organización de la información en tablas, definiendo claves primarias y foráneas.
- 💾 Base de Datos (MySQL): creación e implementación de las tablas para almacenar y administrar la información.
- 📝 Documentación por Proceso (Google Docs o Word): descripción de los procedimientos y etapas realizadas durante el proyecto.
- 🎨 Presentación (Canva): elaboración de una presentación visual para explicar los principales aspectos del trabajo.

 🎯 Objetivos

- Aplicar los conocimientos sobre bases de datos.
- Organizar y relacionar información correctamente.
- Utilizar herramientas digitales para el desarrollo del proyecto.
- Fomentar el trabajo en equipo y la responsabilidad.
